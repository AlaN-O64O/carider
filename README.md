# CaRider — заказ такси через мобильное приложение

Габбасов Алимжан · группа 25-16 · проект CaRider (ЛР №1–6)

Серверная часть и «ходячий скелет» сценария UC-01: экраны Э-01 «Куда едем?» и Э-02 «Стоимость и условия» и операция API `POST /api/quotes/`. Данные пока из заглушки, мобильное приложение Flutter подключится к этому API в ЛР №7.

## Стек

Python 3.12, Flask 3.1, PostgreSQL 16 (в эксплуатации; сейчас заглушка вместо БД), клиент — Flutter 3.
Обоснование — [docs/adr/ADR-001-stack.md](docs/adr/ADR-001-stack.md).

## Как запустить

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
flask --app carider run
```

(macOS и Linux: `source .venv/bin/activate` вместо второй строки.)
Открыть http://127.0.0.1:5000/ — экран Э-01. Введите «ул. Ауэзова, 42» и нажмите «Рассчитать стоимость»: на Э-02 будет 1 850 тг и 14 мин. Остановить сервер — Ctrl+C.

API: `POST /api/quotes/` с телом `{"destination": "ул. Ауэзова, 42"}` возвращает цену, длительность и условия отмены.

## Как проверить

```
python -m unittest
ruff check .
ruff format .
```

## Структура

- `carider/` — серверное приложение
  - `orders/` — модуль «Заказы» (экраны Э-01, Э-02; БП-02, БП-05)
    - `views.py` — слой представления
    - `services.py` — слой бизнес-логики
    - `repository.py` — слой доступа к данным (заглушка)
    - `errors.py` — ошибки, которые соответствуют исключениям UC-01
- `tests/` — автоматические тесты
- `docs/adr/` — записи архитектурных решений

## Соглашения о коде

| Правило | Как в CaRider |
| --- | --- |
| Стиль | PEP 8; форматирование — `ruff format`, длина строки 88; клиент на Dart — `dart format` |
| Имена | Функции и переменные — snake_case, классы — PascalCase, константы — UPPER_CASE; имена в коде на английском |
| Комментарии | На русском; у каждой публичной функции и класса — строка документации, у правила — ссылка на БП-xx |
| Слои | `views.py` вызывает только `services.py`, `services.py` — только `repository.py`; бизнес-правила БП-xx — только в `services.py`, в шаблонах и представлении правил нет |
| Модули | Один пакет на модуль (accounts, orders, dispatch, payments, support); зависимости только по таблице модулей, без циклов |
| Проверка перед коммитом | `ruff check .` — 0 ошибок, `python -m unittest` — OK |
| Коммиты | Conventional Commits: feat, fix, docs, test, refactor, chore; одно изменение — один коммит |
| Секреты | Ключи SMS-сервиса и платёжного шлюза — только в `.env` (файл в `.gitignore`) |
