# Системные тест-кейсы CaRider (для кросс-тестирования)

Запуск: `python -m venv .venv`, `.venv\Scripts\activate`, `pip install -r requirements.txt`, `flask --app carider migrate`, `flask --app carider loaddata demo`, `flask --app carider run`, страница http://127.0.0.1:5000/. Админ-панель: /admin/ (admin / admin).

| ТК-02 | — | Э-01: ввести «нигде» → «Рассчитать стоимость» | Остаёмся на Э-01, текст «Такой адрес не нашли. Проверьте написание или добавьте номер дома» |
| ТК-03 | — | Э-02 для «ул. Ауэзова, 42»: не отмечать согласие → «Заказать» | Э-02, текст «Отметьте согласие, чтобы заказать.»; в /admin/orders/ новых заказов нет |
