# ADR-001. Выбор технологического стека

**Статус:** принято, 19.10.2026.

## Контекст

CaRider — мобильное приложение заказа такси для клиентов и таксистов с веб-панелью оператора. Нужны приложения под Android 10+ и iOS 15+ (Т-1), геолокация, карта и push-уведомления таксисту (Т-2), интеграции с SMS-сервисом, платёжным шлюзом и картами (Т-3). Назначение таксиста — до 15 с при 1000 одновременных заказов (Т-4), сервер БД находится в РК (Т-7), нужны двухфакторный вход и журнал доступа (Т-6). Разработчик один, уверенно владеет Python, срок — 8 недель, бюджет — 0 тг (Т-8, Т-9).

## Решение

| Уровень | Выбор |
| --- | --- |
| Платформа клиента | Android 10+, iOS 15+; панель оператора — браузер на компьютере |
| Язык и фреймворк клиента | Dart 3, Flutter 3 (ветка stable), один код для двух ОС |
| Язык и фреймворк сервера | Python 3.12, Flask 3.1 (REST API, JSON) |
| СУБД | PostgreSQL 16 на сервере в РК; при разработке — SQLite |
| IDE | VS Code (расширения Python и Dart/Flutter), Android Studio для эмулятора |
| Контроль версий | Git + GitHub |
| Качество кода | ruff (линтер и форматтер); тесты: unittest (сервер), flutter_test (клиент) |

## Альтернативы

- **B. Kotlin + Swift + Spring Boot — 3,30.** Три кодовые базы и три новые технологии за 8 недель для одного разработчика (К6, К7).
- **C. React Native + Node.js — 3,45.** Ближайший конкурент (разница 0,25, практически ничья); проиграл по К6: JavaScript для разработчика новый.
- Отсеяны фильтром: веб-приложение (PWA) — нет фоновой геолокации и push на iOS 15; конструктор (no-code) — нет своей логики поиска и сервера в РК.

## Последствия

- (+) Один код Flutter работает на Android и iOS.
- (+) Сервер на знакомом Python; ходячий скелет сервера уже запущен и протестирован.
- (+) PostgreSQL даёт транзакции и блокировки строк: один таксист не получит два заказа (Т-5).
- (−) Два языка и два проекта (Dart и Python); Dart новый, на обучение нужно 1–2 недели.
- (−) Во Flask нет готовых аутентификации, 2FA и ролей: расширения (Flask-Login, pyotp) и журнал доступа придётся подключать самому — риск для НФТ-01 и НФТ-02.
- (−) Flask по умолчанию синхронный: для НФТ-04 нужны несколько рабочих процессов и очередь, проверка — нагрузочным тестом.
- (−) Публикация в Google Play и App Store платная и вне бюджета учебного проекта.
