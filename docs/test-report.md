## Риски и что не проверено

- Нет автоматических тестов оформления экранов; экраны Э-03/Э-04 проверены тестами через HTTP и вручную.
- Одновременные заказы двух клиентов проверены только ограничением СУБД, без параллельных запросов.
- Не проверены нагрузка (1000 заказов, НФТ-04) и безопасность: любой клиент может отменить чужой заказ, потому что входа по SMS ещё нет.
- Данные таксистов и адресов — демонстрационные, поведение на реальных картах и PostgreSQL не проверено.
- Кросс-тестирование (системное тестирование другой командой) не проводилось: дефекты, которых автор не замечает в своём коде, могли остаться.
